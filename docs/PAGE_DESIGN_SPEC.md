## 二、页面类型分类

项目中所有页面归为 **5 种标准类型**，每种类型有固定的布局模板和组件组合。

| 类型 | 代号 | 适用场景 | 核心组件 |
|------|------|----------|----------|
| Dashboard | `DASH` | 首页看板、系统总览 | StatCards + TrendChart + DataTable |
| CRUD List | `LIST` | 埋点管理、系统设置 | FormComponent + TableComponent + DetailDrawer |
| Analysis | `ANLS` | 数据分析 | DataAnalysisHeader + FilterConfig + Chart + Table |
| Tree CRUD | `TREE` | SPM/SCM 管理 | TreeSelector + FormComponent + TableComponent |
| Config | `CONF` | 配置页面 | FormComponent + Descriptions |

### 3.1 首页看板 (Dashboard)

**路由**: `/`
**类型**: `DASH`
**数据源**: `GET /api/homepage/overview`、`GET /api/homepage/trend`、`GET /api/homepage/realtime-events`

#### 布局结构

```
┌─────────────────────────────────────────────────────────┐
│ PageHeader: "数据看板"          [🔄 刷新]                │
├─────────────────────────────────────────────────────────┤
│                                                         │
│  ┌──────────┐ ┌──────────┐ ┌──────────┐ ┌──────────┐  │
│  │ 今日事件  │ │ 活跃用户  │ │ 新增用户  │ │ 7日留存率 │  │
│  │  12,345  │ │  8,901   │ │   456    │ │  42.3%   │  │
│  │  ↑ 12.3% │ │  ↑ 5.2%  │ │  ↓ 1.1% │ │  ↑ 3.4%  │  │
│  └──────────┘ └──────────┘ └──────────┘ └──────────┘  │
│                                                         │
│  ┌─────────────────────────────────────────────────┐    │
│  │  TrendChart (ECharts 折线图)                     │    │
│  │  ── 事件量趋势   ── 活跃用户趋势                │    │
│  │  [7天] [15天] [30天]                             │    │
│  │  height: 400px                                   │    │
│  └─────────────────────────────────────────────────┘    │
│                                                         │
│  ┌─────────────────────────────────────────────────┐    │
│  │  EventTable: 实时事件流                          │    │
│  │  columns: 时间 | 事件名 | 设备ID | 页面 | IP     │    │
│  │  size: small, 自动刷新(30s)                      │    │
│  └─────────────────────────────────────────────────┘    │
│                                                         │
└─────────────────────────────────────────────────────────┘
```

#### 组件清单

| 组件 | 文件路径 | 说明 |
|------|----------|------|
| `Homepage` | `pages/homepage/index.tsx` | 页面容器 |
| `StatCards` | `pages/homepage/components/StatCards/index.tsx` | 4 张指标卡片 |
| `TrendChart` | `pages/homepage/components/TrendChart/index.tsx` | 趋势折线图 |
| `EventTable` | `pages/homepage/components/EventTable/index.tsx` | 实时事件表 |
| `homepageModel` | `pages/homepage/model.ts` | Rematch Model |

#### 组件规格

**StatCards**:
- 布局: `Row gutter={[24, 24]}` + `Col span={6}`
- 每张卡片: `<Card bordered={false}>` 内含:
  - 指标名: `font-size: 13px; color: rgba(0,0,0,0.65)`
  - 数值: `font-size: 28px; font-weight: 600`
  - 趋势: 绿色箭头 ↑（上升）/ 红色箭头 ↓（下降）+ 百分比
  - 底部: 较昨日/上周对比文字

**TrendChart**:
- 容器: `<Card bordered={false}>`, height: 400px
- 图表: ECharts 折线图, `tooltip.trigger: 'axis'`
- 时间切换: `<Radio.Group>` 置于标题右侧（7天/15天/30天）
- 双线: 事件量 + 活跃用户（左右双 Y 轴）

**EventTable**:
- 容器: `<Card bordered={false}>`
- 表格: `size="small"`, 无分页（固定显示最新 20 条）
- 自动刷新: `useInterval` 30 秒轮询
- 列: 时间 | 事件名 | 设备ID | 页面路径 | IP


#### 树节点层级

SPM 和 SCM 均为 4 级层次结构:

| 级别 | SPM 含义 | SCM 含义 |
|------|----------|----------|
| A (Level 1) | 业务线 | 渠道类型 |
| B (Level 2) | 页面组 | 渠道来源 |
| C (Level 3) | 页面区域 | 推广活动 |
| D (Level 4) | 页面元素 | 推广素材 |

## 四、通用交互规范

### 4.1 数据加载

```tsx
// 页面级 Loading
<Spin spinning={loading.modelName.actionName}>
  <Content />
</Spin>
```

### 4.2 操作反馈

```tsx
// 成功
message.success('操作成功')
// 失败
message.error('操作失败，请重试')
// 确认删除
Modal.confirm({
  title: '确认删除',
  content: '确定要删除 xxx 吗？此操作不可恢复。',
  okType: 'danger',
  onOk: handleDelete,
})
```

### 4.3 空状态

```tsx
<Empty description="暂无数据" />
// 或带引导
<Empty description="暂无事件，请先在埋点管理中创建事件">
  <Button type="primary" onClick={() => navigate('/point-manage/event')}>
    前往创建
  </Button>
</Empty>
```

### 4.4 错误边界

每个页面建议包裹 ErrorBoundary:

```tsx
<ErrorBoundary fallback={<Result status="error" title="页面出错了" />}>
  <PageContent />
</ErrorBoundary>
```

### 4.5 权限控制

使用 `permissionId` 控制菜单可见性和按钮权限:

```tsx
// 菜单级
{ meta: { permissionId: PagePermission.POINT_MANAGE_EVENT } }

// 按钮级
{userInfo.permissions.includes(FunctionPermission.EVENT_CREATE) && (
  <Button type="primary">新建事件</Button>
)}
```

### 4.6 URL Query 同步

所有列表页的筛选条件和分页状态必须同步到 URL:

```tsx
// 读取
const { page, pageSize, eventName } = useQuery()

// 写入（通过 useRouter）
refresh({ page: 2, eventName: 'click' }, true)
```

## 五、新增页面模板

### 新增 CRUD List 页面

1. 创建目录 `pages/{module}/{page}/`
2. 创建文件:
   - `index.tsx` — 页面组件
   - `styles.module.scss` — 页面样式
   - `type.ts` — 类型定义
   - `model.ts` — Rematch Model
   - `services.ts` — API 调用
3. 注册路由: `router/page/{Module}.tsx`
4. 注册 Model: `store/models/index.ts`
5. 添加权限: `constant/permissions.ts`

### 新增 Analysis 页面

1. 同上创建基础文件
2. 新增组件:
   - `components/DataFilterConfigArea/index.tsx` — 筛选配置
   - `components/DataChart/index.tsx` — ECharts 图表
   - `components/DataTable/index.tsx` — 数据表格
3. 使用 `DataAnalysisHeader` 替代 `PageHeader`
4. 后端新增 `POST /api/data-analysis/{type}/query` 端点
