# 2026-06-01 后台验证修复

## 问题诊断与修复

### 根因：前端生产构建 React Error #130
- `TeamAddOutlined` 图标不存在于 `@ant-design/icons`（Ant Design 5 移除了该图标）
- 导致首页 StatCards 组件为 undefined → React 崩溃 → ErrorBoundary 捕获
- 所有页面渲染为同一个错误页面

### 修复过程
1. 静态服务器加 API proxy → 解决了登录 API 不通的问题
2. JWT token 直接生成注入 localStorage → 绕过了 login API 限流
3. 修复 `TeamAddOutlined` → `UserAddOutlined` → 重建前端
4. 发现 `page.goto()` 在 SPA 下每次都触发全页重载，React Router lazy 组件没正确加载
5. 改用 **客户端导航**（`pushState` + `popstate`）→ 14/14 页面全部正确渲染

### 最终验证结果
- **14/14 页面全部通过**（首页、事件管理、属性管理、SPM、SCM、事件分析、漏斗分析、用户路径、归因分析、系统总览、元数据、用户管理、角色管理、个人中心）
- **14 个截图 MD5 全部不同** → 证明每个页面都是真实不同的内容
- 各页面 bodyLen 差异明显：55KB~133KB

### 技术发现
1. React Router 在 `page.goto()` 全页重载下 lazy 组件加载有时序问题，客户端 pushState 导航更可靠
2. 前端 `Localstorage.get()` 做 `JSON.parse()`，JWT token 注入必须用 `JSON.stringify()` 包装
3. Ant Design 5 移除了 `TeamAddOutlined` 图标，用 `UserAddOutlined` 替代
