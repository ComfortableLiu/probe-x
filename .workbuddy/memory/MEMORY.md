# Probe-X 项目长期记忆

## 项目定位
- **许可证**：MIT 开源
- **商业模式**：不做 SaaS 商业化，专注开源社区运营和技术生态建设
- **目标用户**：中型互联网/电商/SaaS公司（100-1000人）
- **差异化优势**：微服务架构 + 深度归因分析 + 私有化部署

## 技术架构
- **前端**：React 19 + TypeScript + Rspack
- **后端**：NestJS + TypeORM + gRPC + 微服务架构
- **大数据**：ClickHouse（OLAP）+ Kafka（事件驱动）
- **缓存**：Redis

## 产品战略（2026-07-06 更新）
- **6个月目标**：Star 1→500，月活 1→200，核心模型 4→8
- **P0 优先级**：留存分析、用户分群、Docker 一键部署、SDK 发布 NPM
- **市场进入策略**：技术驱动型中小企业 → 云原生企业 → 数据安全敏感行业

## 用户偏好
- 项目主打 MIT 开源免费，不需要免费版/专业版/企业版定价模式
- 重点关注开源社区运营，而非商业化变现
