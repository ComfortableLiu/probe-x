### 关键技术发现
1. **Chromium Mach port 问题**: WorkBuddy 沙箱阻止 Chromium Mach port 注册（`bootstrap_check_in` Permission denied），改用 Firefox 成功运行
2. **Localstorage.get() JSON 解析**: 前端 `Localstorage.get()` 内部做 `JSON.parse()`，bypassLogin 存值必须用 `JSON.stringify()` 包装
3. **publicPath 映射**: 前端 production 构建的 `publicPath: '/assets/'` 但实际输出在 `css/` 和 `js/` 子目录，自定义静态服务器需要处理路径映射
4. **Ant Design Button 空格**: 按钮文字 "登录" 会被渲染为 "登 录"（中间有空格）
5. **Mock API 拦截**: `page.route()` 在 Firefox 中无法拦截跨端口完整 URL 请求，最终用独立的 mock server 在 8101 端口运行
6. **API baseURL**: 前端 production 模式直接请求 `http://localhost:8101/api/...`，不经过 devServer proxy
